## Known Issues and Solutions

### ES6 Module Loading in Chrome Extensions

**Issue**: When using ES6 modules with dynamic imports in Chrome Extension content scripts, the following error occurs:
```
Failed to load EXTRACTOR-GPT content module: ReferenceError: ExtractionEngine is not defined
```

**Root Cause**: 
1. Chrome Manifest V3 content scripts don't support `type: "module"` directly
2. Dynamic imports via `chrome.runtime.getURL()` require all nested imports to also use absolute URLs
3. Relative imports (`../module.js`) in sub-modules fail when loaded dynamically

**Solutions Implemented**:

1. **content-loader.js**: Attempted to use dynamic imports with `chrome.runtime.getURL()` but failed due to nested relative imports

2. **content-simple.js**: Created a simplified version without ES6 modules that works reliably:
   - Uses IIFE pattern instead of ES6 modules
   - Implements core functionality inline
   - Maintains shadow DOM isolation
   - Provides basic extraction capabilities

**For Production Use**:
- Use a bundler (webpack, rollup, esbuild) to bundle all modules into a single file
- Or rewrite all imports in all modules to use `chrome.runtime.getURL()` 
- Or use the simplified approach with core functions defined inline

**Current Status**: 
- The extension works with `content-simple.js` which provides basic extraction functionality
- Full modular architecture is preserved but requires bundling for production use

### Usage Instructions

#### Smart Pagination Usage
```javascript
// Automatic detection (no selector needed)
automationHandler.settings.smartPaginationDetection = true;
automationHandler.settings.pagination = null; // Let it auto-detect

// Manual selector fallback
automationHandler.settings.pagination = '.pagination-next';
```

#### Page Details Extraction
```javascript
// 1. Start selection mode
chrome.runtime.sendMessage({ action: 'page-details-highlight' });

// 2. User clicks elements (handled by selection engine)

// 3. Extract from all pages
chrome.runtime.sendMessage({
  action: 'page-details-extract',
  urls: ['url1', 'url2'],
  elements: [selectedElement]
});
```
